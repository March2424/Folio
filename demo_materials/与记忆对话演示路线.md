# 「与记忆对话」现场演示路线脚本

> **适用前提**：应用已打包并导入 31 条预设记忆（7 部香港影院票根、3 段合成日常留声、5 本阅读摘抄、6 首旋律、5 组沿途足迹、5 封信件）。  
> **核心展示目标**：在 5～8 分钟内完整展示 **「多模态记忆全量接入 → 精准溯源问答 → 跨载体隐性关联 → 拒答防幻觉 → 对话沉淀与画像/回顾/备份闭环」**。

---

## 第 0 步：会前检查（1 分钟 · 台下完成）

1. 在首页点击右下角 **`✧ 與記憶對話`** 进入对话页（已直接导航到对话主界面）。
2. 点击底部导航第 4 栏 **`模型`**：
   - 填写你的模型名称（如 `deepseek-chat` / `gpt-4o-mini` 等）与 **API Key**；
   - 如使用 DeepSeek 等兼容接口，点击 **`模型服務地址 · 使用其他供應商時修改`** 填入对应 Base URL；
   - 点击 **`儲存並測試模型`**，确认顶部状态栏提示 **连接成功** 后，点底部第 1 栏 **`對話`** 回到空状态欢迎页。
3. *(可选)* 若前面已经做过试聊，点右上角 **`⋮`** → **`開啟新對話`**，让页面停留在居中的 `✧ 把片刻，留成回聲。` 欢迎界面上。

## 第 1 幕：盘点记忆与来源溯源（Single-Source Retrieval）

**展示意图**：证明 Agent 已自动读取相册/票根/留声/书摘中的文字记忆，回答严格附带可点击核验的原文出处。

### 提问 1（可直接点击欢迎页胶囊，或手动输入）
> **Prompt 1：**  
> `我看過哪些電影？`

- **预期效果**：Agent 自动调用检索工具列出 7 部预设电影（《霸王别姬》《星际穿越》《银翼杀手2049》《一一》《重庆森林》《白日梦想家》《薄荷糖》），并准确说出对应香港影院（百老匯電影中心、K11 Art House、英皇戲院 時代廣場、PALACE ifc、MOViE MOViE Pacific Place、FESTIVAL GRAND CINEMA、高先電影院）。
- **演示操作**：
  1. 指着回答气泡下方的金色 **`↗ N 段記憶來源`** 胶囊提示：“AI 说的每一条都有本地原文凭证，不是凭空生成的。”
  2. **点击该来源胶囊** → 弹出**透明液态玻璃来源列表** → 任选一条点开（如《霸王别姬》或《重庆森林》），展示其原文详情弹窗。

### 提问 2（多轮上下文追问）
> **Prompt 2：**  
> `我在铜锣湾和中环看的分别是哪几部？当时各自记下了什么感想？`

- **预期效果**：Agent 根据地址实体精准定位：
  - **铜锣湾（英皇戲院 時代廣場）**：《银翼杀手2049》（`2026.09.26` · 橙黄色废土与维港夜色）；
  - **中环（PALACE ifc）**：《一一》（`2026.08.15` · 洋洋举起相机拍每个人后脑勺的温柔）。
- **口播要点**：“不需要每次重复完整上下文，它能结合前序检索出来的地点和观影随想继续深挖。”

## 第 2 幕：跨模块隐性关联（Cross-Modal Synthesis）

**展示意图**：这是整套系统最惊艳的地方——把**声音、信件、电影、音乐、书摘、足迹**这 6 种原本分散在不同卡片里的记忆，按意象与生活细节串联起来。

### 提问 3（跨「日常留声」×「写一封信」的生活细节联动）
> **Prompt 3：**  
> `我记录过哪些和“厨房”、“水声”或者“外婆”有关的记忆？它们之间有什么联系吗？`

- **预期亮点（必看！）**：
  - 检索到 **日常留声**《晚饭前淘米时的细水流声》（`2026.11.08`，屋企厨房，水柱落入黑内胆白米的沙沙声）；
  - 同时检索到 **写一封信**《外婆旧阳台上的樟树影》（`2026.08.12`，写给外婆：“前几天在家淘米的时候，水柱砸在锅底的声音突然让我一晃神，像是又回到了你老房子的厨房门口”）。
- **口播要点**：“哪怕一条是音频记录、另一条是三个月前写给外婆的信，Agent 依然通过‘淘米’和‘厨房水声’把两端跨越时间的日常感官勾连了起来。”

### 提问 4（跨「音乐」×「足迹」×「阅读手记」×「电影」的主题情绪串联）
> **Prompt 4：**  
> `在我的书摘、歌词和沿途足迹里，有哪些关于“海风”、“夜色”或者“时间流逝”的瞬间？`

- **预期覆盖**：
  - **日常留声**：南丫岛海湾《海边夜空绽开的银色焰火》（`2026.10.02`）
  - **旋律**：deca joins《海浪》（睡前循环与乌龙茶）、王菲《如风》（秋夜叮叮车穿过湾仔）
  - **沿途足迹**：《蓝调时刻的仙女棒》（`2026.09.19` 海风天台）、《从暮色海岸走到夜空焰火》（`2026.11.07` 两幕夜行）
  - **阅读手记**：加缪《局外人》（“海风依然会吹过夜晚”）、马尔克斯《百年孤独》（“春天总是一去不返”）
  - **电影**：李沧东《薄荷糖》（列车倒退二十年）、王家卫《重庆森林》（不会过期的罐头）

## 第 3 幕：边界诚实性验证（Anti-Hallucination / Groundedness）

**展示意图**：展示本地记忆 Agent 严格的「已知/未知边界」——不会为了讨好用户而瞎编不存在的记忆。

### 提问 5（诱导性虚构提问）
> **Prompt 5：**  
> `我之前是不是去过冰岛看极光，或者在东京某家拉面店吃过晚饭？如果有，把具体日期和店名告诉我。`

- **预期效果**：
  - Agent 会明确区分**“想去”与“去过”**：诚实说明在电影《白日梦想家》观影感想里只提到过 *“看完好想买一张飞往冰岛的单程票”*，但记忆库里**并没有去过冰岛看极光的记录**；
  - 对于东京，日常留声《抬头向早晨挥手时的巷口鸟鸣》只提到了 *“文京区街角 · 晴朗秋日清晨”*，**没有任何拉面店或店名记录**，不会编造店名与日期。
- **口播要点**：“市面上通用大模型经常会顺着问题编故事；而我们的记忆 Agent 严格遵守证据链约束，没记过的事绝不编造。”

## 第 4 幕：从「对话」反哺「记忆与画像」的完整闭环

**展示意图**：演示记忆不是静态存档，而是在对话、补充材料、周期回顾与本地备份中不断生长的。

1. **长按气泡提炼新记忆**：
   - 在输入框发送一句随感，例如：  
     `刚才想起十月在油麻地百老汇电影中心看完《霸王别姬》散场，走过街头时风很凉，但心里特别安静。`
   - 发送后，**长按这条黑色用户气泡** → 在液态玻璃菜单选择 **`提議為記憶`（或对应写入记忆项）** → 在审核弹窗微调内容后点击确认写入。
2. **「材料」页快速浏览**：
   - 切到底部 **`材料`** 栏，展示已接入的记忆列表卡片（带状态标签与横向操作 Chip），点击任一卡片 **`查看`** 弹出液态玻璃阅读器；
   - 演示这里也支持手动粘贴日记或导入 `.txt` / `.md` 文本并 **`分析並寫入記憶`**。
3. **「關於我 → 回顧」**：
   - 切到 **`關於我`** 顶部分段条切换到 **`回顧`**；
   - 将开始日期改为 **`2026-10-01`**，结束日期保持 **`2026-11-16`**，标题填 **`秋末冬初的记忆切片`**，点击生成回顾 → Agent 自动汇总十月到十一月中旬跨模块的电影、读书、留声与信件，形成一段叙事式阶段小结。
4. **「管理」与统计收尾**：
   - 点右上角 **`⋮`** → **`記憶覆蓋統計`**，用液态玻璃弹窗展示当前 31 条归档记忆在六大模块中的分布；
   - 在 **`材料 → 管理`** 页面展示 **`匯出記憶備份 (.zip)`** 与 **`匯入記憶備份`**：“所有对话记录、个人特征线索与照片音频都可以一键打包带走，100% 存储在用户自己的设备上。”

## 备用快问清单（现场按时间灵活加测）

- **单点歌词/书摘回忆**：`《冬牧场》和《鼠疫》里我分别摘抄了哪一段话？我写过什么阅读随感？`
- **情感反思类提问（需要已生成「關於我」线索后效果最佳）**：`结合我最近写下的电影感想、书摘和几封信，你觉得这几个月的我更在意生活中的哪些东西？`
- **时间线梳理**：`帮我按时间顺序梳理一下 2026 年 10 月到 11 月我留下过的所有重要片段。`
