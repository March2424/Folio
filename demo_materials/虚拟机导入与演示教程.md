# Folio 虚拟机导入与现场演示简明教程

这份教程串联了从 **记忆压缩包（`preset_memories.zip`）→ 导入虚拟机 → 推入演示素材（`demo_materials`）→ 现场演示** 的完整流程。

---

## 一、如何让虚拟机加载打包好的记忆（`preset_memories.zip`）

### 方式 A：首次安装自动导入（推荐，别人下载项目直接生效）
项目已将 31 条预设记忆打包在 `app/src/main/assets/preset_memories.zip`。应用**首次启动且本地数据库为空**时，会自动解压并导入全部记忆和图片/音频。

1. 如果虚拟机之前装过旧版（库里已有数据），先卸载清库再安装：
   ```bash
   ~/Library/Android/sdk/platform-tools/adb uninstall hk.hkucs.dontwannaforget
   JAVA_HOME="/Applications/Android Studio.app/Contents/jbr/Contents/Home" ./gradlew :app:installDebug
   ```
   *(或在 Android Studio 直接卸载虚拟机上的旧 App 后点击 **Run ▶**)*
2. 启动应用后轻点欢迎页进入展桌，即可直接看到全部 31 条记忆。

### 方式 B：手动导入外部记忆压缩包（`.zip`）
如果你想把**导出的或别人发来的 `.zip` 记忆备份**额外导入运行中的虚拟机：
1. 先把压缩包推进虚拟机的下载目录：
   ```bash
   ~/Library/Android/sdk/platform-tools/adb push 你的记忆备份.zip /sdcard/Download/
   ```
2. 在 App 内打开 **`✧ 與記憶對話`** → 底部第 2 栏 **`材料`** → 顶部分段条切到 **`管理`** → 点击 **`匯入記憶備份`** → 在系统文件选择器里选中 `/Download/` 下的 `.zip` 确认恢复即可。

---

## 二、把演示素材（`demo_materials/`）导入虚拟机

`demo_materials/` 下准备好了 6 个模块的手动创建素材（图片、合成的 `.m4a` 音频及 `填写内容.txt`）：

1. 执行命令将整个演示素材文件夹推入虚拟机手机存储：
   ```bash
   ~/Library/Android/sdk/platform-tools/adb push demo_materials /sdcard/Download/demo_materials
   ```
2. 触发一次媒体库刷新（让相册与音频选择器立刻可见）：
   ```bash
   ~/Library/Android/sdk/platform-tools/adb shell am broadcast -a android.intent.action.MEDIA_SCANNER_SCAN_FILE -d file:///sdcard/Download/demo_materials
   ```
   *(若相册中仍未立刻刷出，在编辑器选图或选音频时点击左上角菜单 → **Files / Downloads（下载）→ `demo_materials`** 即可直接选取。)*

## 三、现场演示推荐顺序（约 6 分钟）

### 1. 展桌首页与基础浏览（1 分钟）
- 轻点开屏 `Welcome to Folio` 进入**展桌**，演示单指拖动画布、双指缩放、左下角小地图定位。
- 随手点一张预设卡片（如《星际穿越》《淘米时的细水流声》《冬牧场》《海浪》）：
  - **光影（电影）**：轻点卡片正反翻转查看便签/剧照与香港影院票根；
  - **留声（声音）**：点击播放条播放合成的 18 秒淘米水流声，点右侧 `⋮` 展示透明液态玻璃菜单；
  - **书信**：点击信封拆开信纸阅读与翻页。

### 2. 现场手动创建一条新记忆（1.5 分钟）
- 从首页点右上角 **全部記憶**（或任意模块内点底部 **目錄** 切换模块），点击左下角 **記下** 新建：
  - **推荐演示「留声」**（使用未入库的第 4 张素材 `demo_materials/02_日常留声_风声鸟叫/`）：
    - 选封面图：`风声鸟叫_封面.jpg`
    - 选音频：`风声鸟叫_音频.m4a`
    - 照 `填写内容.txt` 填入标题、地点与故事保存，展示从零导入图片和声音并立即播放。
  - *(如需继续展示其他模块，按 `01_`～`06_` 对应文件夹的 `填写内容.txt` 照填即可。)*

### 3. 实时双语切换（30 秒）
- 在模块页点击底部 **`目錄` → `語言 / Language`** → 切到 **English**：
  - 展示模块名切换为 `Cinema / Sounds / Reading / Melodies / Trails / Letters`，底部栏切换为 `Write / Desk / Index`；
  - 再切回 **繁體中文**，展示界面即时同步恢复 `記下 / 展桌 / 目錄`。

### 4. 「与记忆对话」AI 演示（3 分钟）
1. **会前预填 Key**：进入 **`✧ 與記憶對話` → `模型`**，填好模型名、API Key（如需自定义地址点开填写）并点 **`儲存並測試模型`** 确认连接成功，切回 **`對話`**。
2. **按脚本依次提问**（完整话术见 [与记忆对话演示路线.md](与记忆对话演示路线.md)）：
   - **来源核验**：问 `我看過哪些電影？` → 展开底部金色 **`↗ N 段記憶來源`** 液态玻璃弹窗查看原文；
   - **跨模态关联**：问 `我记录过哪些和“厨房”、“水声”或者“外婆”有关的记忆？它们之间有什么联系吗？`（串联留声与写给外婆的信）；
   - **防幻觉边界**：问 `我之前是不是去过冰岛看极光，或者在东京某家拉面店吃过晚饭？`（验证不编造未记录事实）；
   - **沉淀闭环**：在 **`材料`** / **`關於我 → 回顧`** 展示记忆卡片、阶段回顾生成与 **`管理 → 匯出完整記憶備份`** 一键打包 `.zip`。
