# Folio

**Folio**是一款以本地存储为主的 Android 生活记忆册应用。你可以记录电影票根、日常声音、读书摘抄、喜欢的旋律、沿途风景或写给未来的信；界面采用深色展桌、纸张质感卡片与透明液态玻璃浮层设计。

**基础功能完全离线，无需账号或后端服务**；AI「与记忆对话」为可选功能，由用户自行配置模型 API Key。

---

## 模块一览

| 模块 | 英文名 | 说明 |
| --- | --- | --- |
| **光影** | Cinema | 记录电影观影感想、香港影院票根信息，支持便签/海报正反翻转。 |
| **留声** | Sounds | 现场录音或导入本地音频，搭配场景照片与声音故事。 |
| **书页** | Reading | 保存书中摘抄与随感，支持以摘抄文字作便签封面及多种纸张器物样式。 |
| **旋律** | Melodies | 留下歌词、封面背景与听歌心情，可自定义字体与模糊氛围。 |
| **足迹** | Trails | 多页纸质图文手账，可自由缩放旋转照片并排版手写文字。 |
| **书信** | Letters | 打字机界面写信、选信封封缄，点击拆信翻页阅读。 |
| **与记忆对话** | Memory Chat | 接入自己的大模型，检索记忆并附出处核验、整理个人线索、阶段回顾与备份导出。 |

## 界面导航与操作

- **展桌首页**：自由拖动、双指缩放记忆画布（含左下角缩略地图与缩放按钮），点击右上角 **全部记忆** 或右下角 **✧ 與記憶對話**。
- **底部栏（模块列表页）**：**記下**（`Write` 新建记录）· **展桌**（`Desk` 返回首页）· **目錄**（`Index` 切换模块 / 进入记忆对话 / 语言切换）。
- **双语切换**：在 **目錄 → 語言 / Language** 中实时切换 **繁體中文 / English**（仅切换界面，已存记忆内容不翻译）。
- **内置预设记忆**：项目已在 `app/src/main/assets/preset_memories.zip` 打包预设记忆，首次安装启动自动导入；现场手工演示素材与话术脚本位于 [demo_materials/](demo_materials/)。

## 快速运行

- **环境**：Android Studio（支持 AGP **9.3.3**）、Android SDK **API 37**、Gradle **9.5.0**（Wrapper 自动管理）、JDK **25**、最低运行系统 **Android 7.0 (API 24)**。
- **构建与安装**：
  ```bash
  ./gradlew :app:assembleDebug   # 生成 app/build/outputs/apk/debug/app-debug.apk
  ./gradlew :app:installDebug    # 安装到已连接的手机或虚拟机
  ```
- **开启 AI 对话（可选）**：进入 **與記憶對話 → 模型**，填入模型名称、API Key（可选填自定义兼容地址），点击 **儲存並測試模型** 即可使用。所有记忆均保存在本地，API Key 经 Android Keystore 加密存储。
